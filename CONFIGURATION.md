# CONFIGURATION

## MONGOOSE

- Install mongoose

```bash
  npm install @nestjs/mongoose mongoose
```

## APPLICATION

- Generate Module Common

```bash
  nest generate module common
```

- Generate Module Infrastructure

```bash
  nest generate module infrastructure
```

```bash
  nest generate module core
```

- Install Winston Logger

```bash
  npm install --save nest-winston winston
```

- Install Zod Validation

```bash
  npm install zod
```

- Install Nest Configuration

```bash
  npm install --save @nestjs/config
```

- Generate Module Middleware

```bash
  nest generate module middleware
```

- Install Nest Jwt

```bash
  npm install --save @nestjs/jwt
```
